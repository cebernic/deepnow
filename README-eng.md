## ⚡ What is DeepNow

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; In today’s world where **tokens** rule, **DeepNow** is an AI model gateway (router) and knowledge‑fusion foundation built for high‑availability, high‑concurrency, and all‑scenario use – both for individuals and businesses. It not only unifies and orchestrates all kinds of isolated large language models (LLM/VLM) and embedding models, but also lets you aggregate them with smart algorithms to combine computing power and provide failover. By integrating resources from multiple model providers, it gives your frontend apps or dev environments the strongest token boost possible. With aggregation, you can easily break through each provider’s TPM, concurrency, and other limits – whether you’re vibe‑coding with a team, building long‑context apps, or handling sudden burst traffic. Basically, DeepNow is like your personal software router for the AI era, except the traffic it manages isn’t TCP/IP packets – it’s token flows. So you can think of DeepNow as a new kind of TR or TG (Token Router / Token Gateway).

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; Once you start using DeepNow, you point all your frontend apps and dev tools to DeepNow’s token endpoint. That gives you unified control over traffic routing, load balancing, and even lets you hot‑swap models on the fly. You no longer need to configure each app with a separate API key from some token provider – just use the key and endpoint generated by DeepNow. Usually, when you want to switch models in your AI apps, you have to edit every app’s endpoint URL and API key with a text editor – super tedious. If those apps are user‑facing, the cost becomes extremely high, especially for agent‑related apps where switching models might break the agent itself or its auto‑configuration abilities. With DeepNow, all your apps effectively gain the ability to hot‑swap models, and you can even implement key‑based model routing – just like OpenRouter’s custom multi‑model functionality. But OpenRouter itself is a remote multi‑model gateway – everything lives somewhere else, completely out of your control. A locally‑running multi‑model AI gateway gives you peace of mind, with no network jitter or security issues.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; But DeepNow is capable of so much more.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; If you’re a team or business admin, you definitely don’t want to buy a separate private key for every employee – if they share those keys freely, it could cost you big. You also want real‑time visibility into how many tokens each employee or app is using, and maybe split costs among multiple people, but you’ve had no tool to do that. Now DeepNow helps: it generates and distributes its own keys, and each key can have its own concurrency limits, model selection, traffic thresholds – and you can revoke them anytime.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; If you want to build a business bot, you don’t need extra tools. Whether it’s internal company knowledge or capturing business expertise, you can feed it to DeepNow with almost no effort – no model training skills required. You instantly get a solution that uses the world’s best model brains to learn and understand your private knowledge, turning it into a private AI / digital employee that “gets” you. When multiple apps call your private AI, they all inherit that knowledge and the ability to logically reason and respond based on it. In strict domains like training, healthcare, research, product demos, or backend maintenance where hallucinations are unacceptable, DeepNow has your back.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; With all the flashy agents and scattered models out there, frontend and backend often speak different protocols. The industry is moving away from the old OpenAI v1/completions protocol toward the more advanced Responses and Messages protocols – but each provider adds its own quirks and “secret sauce”, making compatibility a headache. DeepNow solves that easily. Without buying any remote service, you can locally hook any model into mainstream agents like OpenClaw, Codex, or Hermes – and even enable advanced concurrency to cut down the time those agents spend solving complex tasks. No other AI gateway can do this today.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; In the future, DeepNow will also integrate MCP services, plugins, server‑side tasks, model‑agnostic context maintenance, server‑side skills, and multi‑modal aggregation (e.g., stitching together models with different strengths – one for image/sound recognition, another for graphic generation – because no single model is best at everything). We need to route AI compute on demand.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; In short, DeepNow is becoming an AI infrastructure piece, a powerful compute base, an AI traffic router that can mount all kinds of advanced capabilities.

## ⚡ What pain points does DeepNow solve?

<details>
  <summary><b>🚀 High availability, extreme compute fusion – break through concurrency limits</b></summary>
  <br>
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;You’re probably frustrated: you bought a bunch of token compute, but nothing can actually give you blazing fast, high‑concurrency responses. Regular non‑enterprise model resources come with strict rate limits (RPM, TPM, RPD, etc.). No matter how much you optimize your app, you can’t bypass the provider’s throttling. <b>DeepNow smashes that limitation</b>: with our unique compute‑fusion tech, you just combine multiple cheap personal token plans (or very affordable dev plans) and their combined throughput can reach or even exceed enterprise‑grade standards. You can also aggregate local open‑source models running on different physical devices and centrally orchestrate them – one interface serves many apps, no expensive pro‑grade hardware needed. **Total token freedom**. And for high‑availability business scenarios, your frontend apps never want to see “…high demand, please try again later…” type errors. DeepNow catches those abnormal responses and automatically resends the request using a backup model – your users won’t even notice.
</details>

<details>
  <summary><b>🧠 Smart‑answer (Token‑Aware Optimal Routing)</b></summary>
  <br>
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Beyond same‑model aggregation, multi‑model mixing, disaster recovery, and other scheduling algorithms, DeepNow has its own unique “smart‑answer” algorithm focused on two business scenarios.<br><br>
  1) **Speed‑first inference**: you can bind 2+ super‑fast, cheap models. DeepNow sends the same request to all of them simultaneously. Whichever responds first sends its answer back – the others are discarded.<br><br>
  2) **Inference tier re‑rank**: you order models by their reasoning ability. First, a lightweight model analyzes the intent and key info from the question and classifies it, then passes it to a tiered set of larger models that handle different difficulty levels. That gives you fine‑grained token spending and more accurate results.
</details>

<details>
  <summary><b>🛡️ Compute sharing</b></summary>
  <br>
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Whether you’re an individual AI geek (e.g., heavy Hermes/OpenClaw user) or an enterprise with multiple people using AI, DeepNow lets you share the same compute resources across different apps and users. DeepNow generates and manages its own auth system (API keys). You can give one key to multiple apps you own, or share many keys with many people. Without DeepNow, multiple people in different locations using the same model key often triggers the provider’s risk controls – leading to account bans, privacy leaks, and finger‑pointing. With DeepNow, the real caller is hidden – the provider only sees DeepNow. That makes sharing safe and controllable. DeepNow also tracks token in/out traffic per distributed key and writes it to an internal/external database (sqlite/mysql). You can build your own token usage UI for secondary billing, management, etc.
</details>

<details>
  <summary><b>📦 Agile deployment & strong performance (zero deps, ready to go)</b></summary>
  <br>
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Most open‑source AI apps today are written in Python. Besides installing a mess of interdependent libs (where a wrong version can break everything), you also suffer Python’s inherent performance issues. DeepNow was built from day one to never compromise on performance – it’s enterprise‑grade. It’s written in compiled Go + C, with all components built‑in – no extra installs. Even the UI is embedded in the binary, so no separate serving required. Truly “download and run” in two steps. No tiny components, no heavy Docker. Just pick the pre‑compiled binary for your platform, and you can deploy it on N devices in one second. No need to hand‑write complex config files – everything is done through a super intuitive visual H5 admin panel. Get the service up first, then fine‑tune. That’s the extreme agile experience DeepNow aims for.
</details>

<details>
  <summary><b>🧠 Transparent knowledge base mounting (plug‑and‑play brain)</b></summary>
  <br>
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Both individuals and businesses want to turn their private knowledge into AI memory. <b>DeepNow seamlessly orchestrates any model to process that knowledge</b>. Your frontend apps don’t need to implement complex RAG retrieval logic – DeepNow, while performing inference, directly retrieves relevant knowledge from the bottom layer and weaves it into the context. The system supports custom retrieval fallback policies – for example, if no knowledge is found, it can either block the request or fall back to the model’s own knowledge. Even smarter: the compute‑round‑robin architecture also applies to knowledge retrieval, so no single model provider ever sees your full context – physically reducing the risk of data leaks. For zero‑hallucination (temp 0) professional scenarios, DeepNow uses Inject Prompt tech to align the output from different models into a consistent format, so your private knowledge is recalled in the exact format you request, no matter which model is used. DeepNow’s knowledge system will support multi‑modal recall (images, audio). Each modality can use its own specialized model and cross‑mix outputs, or a single multi‑modal model can handle it directly – but the final inference result fuses everything. Whether it’s text knowledge or structured knowledge graphs, DeepNow can learn and combine them for reasoning tasks, allowing agents and frontend apps to run fully customized, precise task flows.<br><br>
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;**DeepNow’s** core philosophy is to fully decouple “private logic” from “inference models”. Here, large models become pure compute units – they are the instinctive cognitive layer, while the underlying knowledge is your unique AI’s brain. Through DeepNow’s unified gateway orchestration, you can hot‑swap remote/local models anytime, and also switch between different kinds of knowledge bases, even individually remove or restore knowledge fragments to adapt to various scenarios. The core tech involves filtering knowledge semantics (including images), vector space comparison, re‑indexing/re‑ranking, semantic expansion, and other techniques to precisely locate knowledge and reason with real‑time knowledge streams. This achieves effects similar to pre‑trained private models without the cost of actually training one.<br><br>
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Additionally, DeepNow will have self‑learning and memory storage – it can turn all request content into memory (with permissions) with no length limits.
</details>

<details>
  <summary><b>🌐 Tree‑like distributed compute network (infinite cascade & chaining)</b></summary>
  <br>
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;**DeepNow** nodes can cascade into each other! Beyond pure compute sharing, the stateful memory and private knowledge systems can be seamlessly called by other DeepNow instances – because context and knowledge recall are already deeply fused into the streamed responses. You can build multiple DeepNow nodes, each specialized in a different domain (e.g., node A = employee knowledge graph brain, node B = product brain, node C = business analysis brain), then use an upper‑layer node to aggregate them, creating a super private AI hub with full‑domain capabilities. Frontend apps can then connect to node A, node B, or the top‑level super node based on permissions and needs.
</details>

## ⚡ Quick Start

DeepNow is fully statically compiled with embedded assets – ready to go, no complicated deployment. Besides configuring the endpoints for your LLM and embedding models, you don’t need to install any third‑party components. The release version needs no Docker, npm, or other environments, has zero external dependencies, and is cross‑platform. One clean, maintenance‑free binary runs everywhere (includes GUI dashboard, vector DB, relational storage, etc.).

```bash
# 1. Run the DeepNow server
Linux:
./deepnow

Windows:
just run deepnow.exe

# Once you see the console output and “listening” message, it’s running. The default service port binds to all IPs on the machine.

After startup, you can use the admin UI.

# GUI Dashboard binds to port 8084 by default, access via http (for safety, bound to 127.0.0.1 only)

Open http://127.0.0.1:8084/ in your browser – you can change the port later in the settings.

# Note: By default, the endpoint service uses HTTPS. The first time you run it, DeepNow generates a 10‑year self‑signed certificate.
# Some clients that strictly validate certificates may reject it, so it’s best to configure a real certificate and access via a domain name.
