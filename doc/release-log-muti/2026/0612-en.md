## **Deepnow — The Most Powerful AI Compute Gateway**

### Changelog 2026-06-12

#### 1\. Full RAG System \& UI Rework

The entire RAG engine and frontend UI have been completely rebuilt\. **`rag.*.whl`****Please delete all  files \(including \) if upgrading from old versions**\.

As one of Deepnow’s flagship core features, the upgraded RAG system supports full lifecycle knowledge management: knowledge ingestion, addition, deletion, precise single\-chunk removal, and scenario\-based temporary enable/disable of knowledge bases\.

Powered by a **SQLite3 \+ C\-based vector implementation**, the system delivers high concurrency comparable to professional standalone vector databases\. Cascading multiple Deepnow gateways enables unlimited distributed multi\-level knowledge base scaling\. A built\-in re\-ranker module will be added in future updates to further accelerate LLM inference\.

**Core RAG capabilities:**

- **Model\-agnostic**: Supports knowledge ingestion with all model loading modes

- **High\-concurrency real\-time management**: Concurrent embedding and instant knowledge on/off switching, ideal for enterprise\-grade high\-throughput retrieval scenarios

- **Gateway\-level toggle**: Built\-in RAG Slider to globally enable/disable local knowledge injection for all gateway inference tasks

#### 2\. Responses API Protocol Optimization \& Full Compatibility

Fixed an issue where multi\-turn image chats caused excessive historical dialogue contamination in RAG retrieval\. Fully implemented standard OpenAI Responses protocol specifications\.

Deepnow now supports all legacy OpenAI\-compatible models and all Responses\-protocol clients \(chat apps, AI agents, with/without SSE streaming\)\. It delivers native compatibility with **Codex and Hermes**, including Codex direct image recognition\.

Upcoming: Responses passthrough options and Messages protocol translation, to enable full Claude Agent support\.

#### 3\. Multi\-Modal Fallback via Secondary Model Routing

Added hybrid multi\-modal inference support: pure\-text primary models can be paired with a secondary vision model to enable image analysis capabilities\.

Deepnow intelligently routes client requests to matched models and returns unified\-format responses\. For downstream clients, the gateway acts as a standard unified multi\-modal inference endpoint\.

#### 4\. Mainstream LLM Preconfigurations

Built\-in ready\-to\-use configurations for all mainstream large language models\.

#### 5\. General Fixes

Miscellaneous improvements and sanitization for global chain\-of\-thought processing\.
